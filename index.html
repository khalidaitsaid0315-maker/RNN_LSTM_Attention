RNN/LSTM Attention

Application Streamlit pour comparer Ridge, MLP-RNN, MLP-LSTM et un modele avec attention sur des series temporelles financieres.

GitHub Pages affiche cette page statique. Pour executer l'application interactive Streamlit, lancez-la localement ou deployeez-la sur Streamlit Community Cloud.
Ouvrir le depot GitHub Streamlit Community Cloud

Lancer localement

git clone https://github.com/khalidaitsaid0315-maker/RNN_LSTM_Attention.git
cd RNN_LSTM_Attention
pip install -r requirements.txt
streamlit run app.py
